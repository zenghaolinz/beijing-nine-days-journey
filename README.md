# 京日慢游 · 北京九日旅行手册

可以根据住处所在片区调整的北京九日旅行网页。支持酒店、民宿和青旅选择、自填住处、出发日期、预约排程与行程导出。个人偏好仅保存在使用者的浏览器中。

这是现有旅行网页的 GitHub Pages 副本。发布来源为 `main` 分支根目录，无需安装依赖或构建。

住宿房价与库存请通过房源详情页按实际入住日期查询；交通时间与步行距离为规划估算，景点开放和预约安排以出行当天官方信息为准。

## 三条路线方案

- **全景紧凑**：第五天游览颐和园与圆明园，第六天集中参观北大、清华，适合想尽量多看的旅行者。
- **均衡分区（推荐）**：第五天颐和园与北大，第六天圆明园与清华，每天一座园林配一所校园，减少同一天连续暴走。
- **省腿慢游**：第五天只游颐和园，第六天游圆明园并从两所校园中择一，给体力和预约变化留余量。

路线方案会与住处片区、出发日期和已填写的预约一起排程。固定预约优先；遇故宫常规周一闭馆时，系统自动与相邻的景山、南锣鼓巷日互换。

## 预约排程与住宿片区比价

“我的预约”支持八个景点的日期、入场时刻和游览时长。固定预约优先，其他景点按距离和剩余时间安排；重叠或赶不上的预约会标红，无法排入的景点单独列出。没有录入有效入校预约时，北大、清华只列为备选，不进入自动生成的时间表。自动排程保持地坛→雍和宫→国子监、天安门广场→故宫的同日顺序；若固定预约与该顺序相反或超出网页预设的游览窗口，会保留预约并提示核对。交通为规划估算，请核对实际导航、门票时段和车次。

“住宿片区比价”按五个片区展示 20 处住宿样本。每个片区分别计算青旅床位与独立房间的参考最低价、最高价，并显示对应房源；支持类型筛选、查看房源详情和记录自己查到的报价。自填报价与入住、退房日期绑定，保存于当前浏览器；不会上传到服务器，也不跨设备同步。

参考数值来自 2026-09-20 至 09-23 查阅的房源或订房平台页面，部分页面展示更早入住日期的样本。英镑价格按中国银行 2026-09-23 参考牌价约 1 英镑 = 8.94 元人民币换算。每张卡片都列有原页面数值、适用说明和来源链接。片区高低价只表示本站收录样本，不能视为全市场价格或当前可订报价。住宿页使用本地托管的北京街道底图，可点击五个住宿片区并同步筛选房源。底图裁切自 Kirill Shrayber 的 [Beijing China street map.svg](https://commons.wikimedia.org/wiki/File:Beijing_China_street_map.svg)（CC0）；叠加位置以故宫、颐和园和北京南站校准，并核对清河站与国贸。片区色带表示大致范围，不是行政边界，也不表示步行距离。手机先显示全图，可放大查看街道。
