# 京日慢游 · 北京九日旅行手册

可以根据酒店所在片区调整的北京九日旅行网页。支持酒店选择、自填住处、出发日期、轻松模式、预约清单与行程导出。个人偏好仅保存在使用者的浏览器中。

这是现有旅行网页的 GitHub Pages 副本。发布来源为 `main` 分支根目录，无需安装依赖或构建。

酒店房价与库存请通过页面内的品牌官网查询；交通时间与步行距离为规划估算，景点开放和预约安排以出行当天官方信息为准。
